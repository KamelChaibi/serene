## Install

1. Download `Serene-v1.0.0.apk` to your Android device.
2. Open the file from your Files app or browser.
3. If prompted, allow your browser or file manager to install unknown apps.
4. Tap **Install**, then open **Serene**.

Serene is not distributed through the Google Play Store. For older or newer
releases, check the [GitHub Releases page](https://github.com/KamelChaibi/serene/releases).

## Verify the download

```bash
# Linux / macOS
sha256sum Serene-v1.0.0.apk
```

```powershell
# Windows (PowerShell)
Get-FileHash .\Serene-v1.0.0.apk -Algorithm SHA256
```

The output must match the SHA-256 value above.
